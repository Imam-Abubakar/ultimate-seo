## [1.0.0] — 2026-10-28

### Added
- `ultimate-seo` skill with a seven-phase workflow (detect → understand → audit → implement → verify → playbook → report) and a 12-point SEO baseline.
- 13 framework guides: Next.js (App and Pages Router), React/Vue/Svelte SPAs, Remix/React Router v7, Astro, Nuxt, SvelteKit, Gatsby, Angular, plain HTML, static site generators, server-rendered frameworks, and CMS platforms.
- 10 topic references: metadata, technical SEO, structured data, performance, AI search, international, content strategy, local SEO, e-commerce, launch and monitoring.
- Scripts: `detect_stack.py`, `seo_audit.py`, `validate_jsonld.py`, `generate_sitemap.py`, all standard-library Python.
- Assets: `ULTIMATE-SEO.md` playbook template, `robots.txt` with AI-crawler policy, `llms.txt`, and 10 JSON-LD templates.
- 63 unit tests, a package linter, four end-to-end eval cases, CI, and a Claude Code plugin marketplace manifest.
